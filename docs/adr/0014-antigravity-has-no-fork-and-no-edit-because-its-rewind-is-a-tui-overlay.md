# Antigravity has no Fork and no Edit, because its rewind is a TUI overlay

`agy` 1.2.7 does ship `/rewind` (alias `/undo`) and `/fork` (alias `/branch`), which is why their absence needs recording: both are interactive picker commands, not callable operations. Their command types in the binary carry only `Aliases`/`Description`/`Execute`/`Name`, where argument-taking commands such as `/model` also carry `ArgHint` and `CompleteArg`, and print mode does not expand them at all — `agy -p "/fork" --conversation <id>` handed the literal string to the model, which read it as a filesystem path and tried to stat it. Resume is append-only on top of that: `--conversation <uuid>` continues at the end, there is no resume-at-a-step and no branch subcommand. Neither route `IProviderSessions` offers is therefore reachable — no `resolveEditAnchor` for a runtime that can resume partway, no `rewindSession` for one that branches instead — so `forkSession`, `resolveEditAnchor` and `rewindSession` are left unimplemented, and `supportsFork`, `supportsSessionForking`, `supportsMessageEditing` and `rewindRestoresFiles` are all false.

**Considered Options**: driving the TUI through a pty and sending `/rewind` plus cursor keys — rejected, it is screen-scraping a layout belonging to a CLI that self-updates by default and shipped 50 releases between 1.0.0 and 1.2.6. Synthesising a branch on disk by copying `brain/<conversation-id>/` and truncating `conversations/<id>.db` — rejected, that file is opaque protobuf with integer step discriminators, and the matching index row would have to be written into `conversation_summaries.db`, which the Antigravity IDE shares and this fork treats as read-only.

**Delete this** when `/rewind` or `/fork` accepts an argument, or headless mode gains an equivalent. At that moment Edit arrives through `rewindSession` — the fork-then-repoint shape Codex uses — rather than through `resolveEditAnchor`, because resume stays append-only either way.
